# mkorosec.github.io

Static portfolio and browser projects, hosted on GitHub Pages.

Run `python3 -m http.server 4185` and open http://localhost:4185.

The project showcase lives at `/portfolio/` in `portfolio/index.html`; styles and favicon are in `assets/portfolio/`. Edit the project links and descriptions directly in the HTML. Travelogue lives in a separate repository and is linked at https://mkorosec.github.io/travelogue/; its GitHub Pages deployment remains independent.

The homepage (`index.html`) is the geography quiz, also available at `/quiz/`. Its shared assets and daily questions remain at the repository root. Existing quiz share URLs with a category fragment continue to work at both routes.

The portfolio uses a catalogue layout: all eight published projects have equal treatment and alphabetical ordering, with a preview beside each description. The earlier Ramona design is linked from its entry.

The portfolio uses real project screenshots in `assets/portfolio/screenshots/`. These capture the initial interface without personal data. The quiz preview is cropped to its question panel; the map background currently displays an upstream tile-provider API-key message, so a full-map screenshot would not make a useful preview. Re-capture previews when the application UI changes.

Visit Sabunike links to the independently hosted [Apartments Napros website](https://mkorosec.github.io/visit-sabunike/). The portfolio also lists Digital twin of a building (coming soon, linked to its GitHub repository) and Bomberman multiplayer (in progress).

HYROX Venues links to its independently hosted [project site](https://mkorosec.github.io/hyrox-venues/). Its preview is a graphic until a screenshot can be captured.
